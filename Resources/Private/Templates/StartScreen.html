Access Details

When you launch your EC2 instance for the first time, access credentials such as a random system password are generated automatically. To log in to the TYPO3 backend, you will also need to create a backend user with administrator privileges.

Start by establishing a secure SSH connection to the server using the private SSH key you configured during the EC2 launch (username: admin). For example, the following command uses the file private.key as your private key: 

ssh -i private.key admin@{hostname}

After logging in as the "admin" user, switch to the "typo3" user:

sudo su - typo3

Next, navigate to the TYPO3 project directory:

cd /var/www/typo3v14/

Create the TYPO3 backend user "admin":

./vendor/bin/typo3 backend:user:create --admin --maintainer --username admin

You will be prompted to set a secure password. Use the chosen username (e.g. admin) and the password to log in to the TYPO3 backend.

If you encounter any issues, refer to the documentation.

Backend Login

The TYPO3 backend is the administration interface that lets you configure and manage the system, create additional backend users, and build and maintain your website content.

Before proceeding, ensure that you have created a backend user and retrieved the access details.

To access the TYPO3 backend, simply add /typo3 to the end of your instance's URL. For this instance, the backend is available at:

http://{hostname}/typo3
